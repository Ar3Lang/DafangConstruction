Dafang Construction 大方建材

传统的建材方块规矩，方整，每一块建材都必须严丝合缝地填满那 1x1 的网格。大方建材提供了一种全新的建材思考方式，不同于普通建材的网格思维，我们基于 Fusion Mod 的 Pattern 渲染模式，让你可以做出大型长条效果的砖块，即刻打破方寸之限。

大方建材的方块贴图写实，灵感多来源于现实中的大型公共建筑所使用的建材，贴图分辨率为32x32。建材不从游戏中自然生成，但可以合成获取，并通过切石机处理获得不一样的质感或尺寸。此外模组还提供了原版台阶、楼梯与墙的基本形态。注意，请一定要在客户端加入 Fusion 模组以确保正确渲染。

即使技术上完全可以实现，我们暂时不考虑加入连接纹理，拿到方块，大大方方地填充到合适的地方，开箱即用，就是本模组的设计哲学。

Dafang Construction
Traditional building blocks are rigid and uniform; every piece must fit perfectly within a strictly defined 1x1 grid. Dafang Construction introduces a completely new way of thinking about materials. Breaking away from the standard "grid mindset," we utilize the Pattern rendering mode powered by the Fusion Mod, allowing you to create large-scale, elongated brick effects that instantly shatter the limitations of single-block boundaries.

The textures in Dafang Construction are photorealistic, drawing inspiration from materials used in modern, large-scale public architecture, all rendered at a 32x32 resolution. These blocks do not generate naturally in the world; instead, they are obtained through crafting and can be further processed via the Stonecutter to achieve different textures or dimensions. Additionally, the mod provides standard Slabs, Stairs, and Walls for all material types.

Note: Please ensure the Fusion Mod is installed on the client side to guarantee correct rendering.

Even though it is technically feasible, we have intentionally chosen not to implement connected textures at this time. Pick up a block, place it boldly where it belongs, and enjoy an "out-of-the-box" experience—that is the core design philosophy of this mod.
